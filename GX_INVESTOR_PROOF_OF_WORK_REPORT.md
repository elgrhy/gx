# GX Language — Proof of Work

> See [README.md](README.md) and [GX_IMPLEMENTATION_SUMMARY.md](GX_IMPLEMENTATION_SUMMARY.md).

The GX language is a working Rust program at github.com/elgrhy/gx.

- `cargo test` — 24 passing tests covering lexer, parser, and interpreter
- `cargo clippy -D warnings` — passes on ubuntu, macos, windows
- `docs/examples/` — runnable `.gx` programs: hello world, calculator, agent, AI assistant, package interop
- GitHub Actions CI — automated verification on every push
